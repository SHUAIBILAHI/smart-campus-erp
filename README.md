# Smart Campus & Student Management System

Java (Spring Boot) + H2 database + HTML/CSS/JavaScript.

## Run (GitHub Codespaces)
1. Open the repo in a Codespace.
2. Terminal: `mvn spring-boot:run`
3. Open port 8080 from the PORTS tab.
